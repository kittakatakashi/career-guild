# 用語集

| 用語 | 意味 | 備考 |
|---|---|---|
| 査定 | 経歴書をAIが解析し、スキルのレベルを判定してステータス画面を作る一連の処理 | UI上の表現 |
| スキル軸 | 評価する能力の項目（例：PM経験、提案力、技術力） | 定義は T02-1 |
| 判定基準（チェック項目） | スキル軸ごとに、レベル順に並んだ「〜の経験がある」形式の基準 | AIは各項目の有無だけを判定する（D-006） |
| レベル | 判定基準の充足状況から機械的に算出される段階（Lv1〜Lv5 を想定） | 算出ルールは T02-2 |
| 表示値 | レベルをRPG表示用に変換した数値（0-100 等） | 算出ルールは T02-2 |
| クラス（職業） | 経歴から推定するRPG上の職業（例：プリセールスコンサルタント） | 判定方針は T02-4 |
| 根拠引用 | 判定の根拠として経歴書から引用した記述 | 結果画面で表示する |
| 決定台帳 | `docs/decisions.md`。1行1決定で ID（D-xxx）を振る | |
| 状態ファイル | `STATE.md` と子タスクファイル。常に最新だけを書く | 経緯は log/ |
| E1〜E4 | Before/After 比較実験（規約・権限・品質・定型作業） | roadmap 4章。実施は MVP 後（D-003） |
| 無料枠 / 有料枠 | Gemini API の課金区分。無料枠は入力が製品改善に使われる | D-010 |
