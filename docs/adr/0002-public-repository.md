# ADR-0002: 公開リポジトリと個人情報の扱い

- 日付: 2026-10-17
- ステータス: 承認

## 背景
CLAUDE.md や hooks などの設定が育っていく過程を、講義・ブログの教材としてそのまま見せたい。
一方、企画段階の議論メモやプロトタイプには実名・勤務先などの個人情報が含まれている。

## 選択肢
- A: 非公開リポジトリで開発し、必要な部分だけ後で切り出して見せる
- B: 公開リポジトリで開発し、個人情報は最初から除外する

## 決定
B。

## 理由
- 設定の変更履歴を git 履歴ごと見せられるのが教材として一番強い
- 後から切り出すと、育った過程が失われる

## 影響
- 企画段階の議論メモは `private/`（gitignore 対象）に置く
- プロトタイプやテストデータは架空の人物データにする
- `.env*` と `private/` は `.gitignore` と Claude Code の `permissions.deny` の両方で保護する
- MVP（APIキーがフロントに露出する構成）は一般公開しない
