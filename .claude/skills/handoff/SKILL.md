# handoff：状態を書き出す

次の会話が「`tasks/INDEX.md` と子タスクファイルを読むだけ」で再開できる状態にする。
ルールの詳細は `.claude/rules/task-state.md`。

## 手順

1. **この会話で決めたことを洗い出す**
   - `docs/decisions.md` に未記入の決定があれば追記する（1行1決定、決定を変えた場合は旧行の状態も更新）
2. **作業中の子タスクファイルを更新する**（上書き。経緯は書かない）
   - 済んだこと（成果物のパス付き）
   - やめたこと・採らなかった案と理由（この会話で却下した案を漏らさない）
   - 未決・保留（誰が・いつ決めるか）
   - 次の一手（1つだけ）
   - 冒頭の更新日
3. **経緯を log に追記する**
   - `log/YYYY-MM-DD.md` に、試したこと・詰まったこと・議論の流れを短く追記する
4. **親の STATE.md と `tasks/INDEX.md` を更新する**
   - 子タスク表の状態、親の次の一手
   - 子タスクが全部完了なら、親を `完了` にして `tasks/_done/` に移す
5. **用語が増えていれば `docs/glossary.md` に追記する**
6. **AI駆動開発の気づきがあれば `docs/devlog/` に書く**（なければ省略）
7. **ユーザーに報告する**
   - 更新したファイルの一覧
   - 次の会話の最初に伝える一文（例：「`tasks/INDEX.md` と T02-1 を読んで、次の一手から始めて」）

## 注意
- 状態ファイルに経緯を書かない。迷ったら log に書く
- 公開リポジトリなので、実在の個人名・勤務先を書かない（`.claude/rules/privacy.md`）
