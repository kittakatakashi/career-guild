# 公開リポジトリと個人情報のルール

このリポジトリは公開前提（D-002 / ADR-0002）。

## コミットしないもの
- 実在の個人名・勤務先・顧客名・取引先名（会話や議事録で出てきたものも含む）
- 実際の経歴書データ（テストデータは架空の人物で作る）
- APIキー等のシークレット

## 置き場所
- 個人情報を含む資料・議論メモは `private/`（gitignore 対象、Claude は読まない）
- `docs/materials/` に置く資料は、マスキング済みのものだけ
- 固有名詞が必要な文脈では「提案先A社」「協力者B」などに置き換える

## 外部APIへの送信
- Gemini API の無料枠は入力が製品改善に使われる。無料枠で送るのは架空データ、または本人が許容したデータだけ（requirements 5.2）
